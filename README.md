# Kiwami (極)

Offline-first Japanese dictionary PWA.

## Project overview

Kiwami is a Vue-based Japanese dictionary that runs fully offline once its dictionary database is available. The app is designed to work as a PWA on iPhone and Mac without requiring an app store or a hosted backend for core lookup.
